Traccar GPS Connector for Odoo Fleet

This module integrates Traccar GPS tracking server with Odoo Fleet. V 1.0

Main Features

  • Automatic GPS position synchronization
  • Store latitude and longitude in vehicles
  • Open vehicle location in Google Maps
  • Copy GPS location link
  • Share location via WhatsApp

Planned features for upcoming version

  • Real-time map update
  • Configurable synchronization interval
  • Instant location request
