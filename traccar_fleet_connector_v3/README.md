# Traccar GPS Connector (v3)

This module connects **Odoo 16 Fleet** with a **Traccar GPS server** through its API.

## Features

- Menu inside **Fleet → Traccar GPS Connector**
- Store the **Traccar server URL and API token**
- Automatically updates the following vehicle fields:
  - `x_location_latitude`
  - `x_location_longitude`
  - `x_uniqueid`
  - `x_ultimafecha`
- Automatic synchronization every **1 minute**

## Requirements

- Odoo 16
- Fleet module installed
- A running Traccar server
